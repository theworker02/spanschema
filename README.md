# spanschema

Span filesystem schema paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/spanschema/

## Install / run

```bash
git clone https://github.com/theworker02/spanschema.git
cd spanschema
node src/cli.js
node --test
```
